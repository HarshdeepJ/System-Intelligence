# Ambient glow prototype — throwaway

Question: what should a formless, top-center System Intelligence presence look
like? Three structurally different directions are switchable with `?variant=`:

- `A` — Living Halo: the selected direction, now using an opalescent profile
  with a soft white core, arctic cyan, periwinkle, lilac, and restrained blush.
- `B` — Edge Aura: light travelling through the physical screen edge.
- `C` — Light Seed: an almost absent point of light with a downward wash.

Run once from the repository root:

```powershell
powershell -ExecutionPolicy Bypass -File .\ui\GlowPrototype\run.ps1
```

Use the bottom arrows or keyboard left/right arrows to change variants. Use the
top-right controls to compare idle, listening, thinking, concern, and resolved
states. This prototype is intentionally disconnected from telemetry and must
not be promoted directly into production code.
